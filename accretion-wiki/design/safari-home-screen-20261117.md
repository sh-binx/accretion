# Safari 홈 화면 실행

독립 배포의 iPhone Safari 일반 탭에는 전체 화면 API를 사용할 수 없을 때 시작·정지 메뉴에 홈 화면 실행 방법을 보여 준다. 홈 화면에서 열린 상태는 `display-mode: standalone`과 Safari의 `navigator.standalone`으로 확인한다. 브라우저가 전체 화면을 지원하면 기존 버튼으로 요청한다. 일반 탭의 주소창을 코드에서 강제로 없애지 않는다.

독립 배포는 배포 디렉터리에 상대적인 매니페스트와 앱 아이콘을 함께 제공한다. 포털 ZIP은 임베드 게임이므로 설치용 메타와 에셋을 제외하며, 기존 두 파일 계약을 유지한다. 브라우저의 저장 키와 API 경로는 그대로다. Safari 탭과 홈 화면 앱 사이에 데이터가 공유된다는 보장은 없다. 오프라인 실행을 약속하지 않으며 새 서비스 워커를 두지 않는다.

근거: [WebKit의 홈 화면 웹 앱 설명](https://webkit.org/blog/13878/). 검수 범위와 실기 결과는 `.superpowers/sdd/2026-11-16-completion/task-4-report.md`를 참조한다.
