# 비행 HUD 및 진화 선택

2026-11-15, 작업 브랜치. 근거: 오너의 테두리형 버튼·카드 개선 요청 및 960×600 정상 입력 플레이 관찰. 기존 천체 렌더·흡수·밸런스 규칙은 이번 UI 변경 범위 밖이다.

- 주행 중 가장 중요한 정보는 현재 질량, 다음 성장 문턱, 추격/충격파 경보다. 화면 위는 이를 읽는 데 쓰고, 점수·시간·최고 질량은 우측 보조 열에 둔다. 퀘이사부터 은하 중심 흡수가 목표 문구로 올라오고 우측 나침반을 함께 쓴다. 교육 토스트는 중앙 시야에서 좌하단으로 옮긴다.
- 공통 에너지를 쓰는 능력은 하나의 조작대에 두고 잔량, 사용 가능, 사용 직후를 구별한다. 붙잡기는 에너지를 소비하지 않는 독립 기능으로, 누르고 있는 동안만 활성 상태가 된다. 키보드 입력과 터치의 명칭은 일치시키되 터치에는 키캡을 노출하지 않는다.
- 진화 옵션의 도식, 요약, 수치, 물리 설명 순서를 맞춘다. 이득/대가는 부호와 방향으로 비교한다. 한 번 선택하면 바로 적용되고, 숫자키와 기본 버튼 조작, 터치 모두 같은 적용 경로를 쓴다.
- 수동 정지와 탭 숨김·성공 결과 정지는 한 판정으로 합친다. 운영판과 같이 세로 플레이를 허용하며 회전만으로 정지하지 않는다. 재개 조건은 모든 정지 원인의 해소이며, 정지 중 이동 입력과 선행 포획 입력을 유지하지 않는다. 포털 gameplayStart/Stop 신호는 중복 없이 짝을 맞춘다.
