# ACCRETION — 게임 기획 v1 (2026-07-23)

> 코드명 ACCRETION(블랙홀로 물질이 빨려드는 실제 천체물리 용어 — 변경 가능). 오너 리뷰 대기.

## 한 줄
**당신은 블랙홀이다. 우주를 미끄러지며 먹어치워 커지되, 당신은 끊임없이 증발한다 — 멈추면 사라진다.**
(Holey.io식 손맛 + 실제 물리가 규칙 + 3D 중력 렌징.)

## 재미의 축 (먼저 — 이게 핵심)
클론과의 차이는 "무엇을 얹었나"가 아니라 **"어떤 긴장이 매 순간 도는가"**다.

1. **미끄러지는 손맛** — 관성 있는 활공(무게감 있는 드리프트). 방향 전환에 관성이 붙어 "조종하는 맛".
2. **삼키는 쾌감** — 먹힌 천체가 즉시 사라지지 않고 **강착원반으로 나선을 그리며 빨려든다** → 예고+보상. 화면 흔들림·질량 카운터 틱·소리.
3. **핵심 훅 = 호킹 복사 축소 타이머** — 블랙홀은 **끊임없이 증발한다**. 안 먹으면 서서히 줄어들고, **작을수록 더 빨리** 증발한다(실제 물리!). → **캠핑 불가, 늘 전진**(상어가 멈추면 죽듯). Hole.io엔 없는 압력. 이 하나가 게임을 "또 하나의 hole"에서 분리한다.
4. **밀고-당기는 긴장** — 축소 타이머는 "공격하라(먹어라)"고 밀고, 더 큰 블랙홀은 "조심하라(피하라)"고 당긴다. 이 줄다리기가 재미.
5. **규모의 스펙터클** — 성장하면 **카메라가 줌아웃**되며 "내가 이만큼 커졌다"가 드러난다. 소행성 먹던 내가 → 별을 → 은하 중심을. "Powers of Ten"의 경외감.
6. **즉각 가독성** — 초록 후광=먹어도 안전, 붉은 후광=나를 먹음. 스냅 판단 가능(재미는 명료함에서).

## 차별화 (경쟁작 대비 — [research](../research/competitive-2026-07-23.md))
- **2D 클론(Hole.io/Yumy)이 구조적으로 못 하는 것**: 3D 중력 렌징(배경별이 휘어짐)·강착원반·광자 고리 → **진짜 블랙홀처럼 보임**(M87*/인터스텔라 가르강튀아 룩).
- **아무도 규칙으로 안 쓴 것**: 호킹 축소 타이머·조석 파괴·질량 위계를 **팝업이 아니라 게임 규칙**으로. 놀다 보면 저절로 배움.
- **교육 천문게임(앱·보드)이 못 준 것**: 진짜 아케이드 손맛.

## 과학 = 규칙 매핑 (차별점의 실체)
| 실제 현상 | 게임 규칙 | 재미 역할 |
|---|---|---|
| 호킹 복사 — 작은 BH일수록 빨리 증발 | 상시 축소 타이머, 작을수록 가혹 | **핵심 압력** — 못 멈춤 |
| 슈바르츠실트 반지름 ∝ 질량 | 먹는 반경(입)이 질량 따라 커짐 | 성장이 체감됨 |
| 조석 파괴(스파게티화) | 더 큰 BH 근처 = 내가 먹힘 | "큰 것 회피" 긴장, 진짜로 |
| 강착원반(낙하 물질 나선) | 먹힌 천체가 원반으로 나선 낙하 후 소멸 | 삼키는 손맛 + 성장 비주얼 |
| 중력 렌징 | 배경별이 나를 중심으로 휨, 질량 따라 강해짐 | 시그니처 룩(2D 불가) |
| 질량 위계(항성/중간/초대질량) | 실제 질량대에서 티어업, 새 먹이 해금 | 스펙터클 + 실제 학습 |
| (옵션) 시간 지연 | 큰 BH 근처서 슬로모 버블 → 클러치 회피 | 짜릿한 순간 + 진짜 |

## 성장 = 실제 우주 규모 (학습이 진행에 내장)
- **항성질량 BH**(~3–100 M☉): 소행성·행성·달을 먹음
- **중간질량 BH**(10²–10⁵ M☉): 별·성단
- **초대질량 BH**(10⁵–10¹⁰ M☉): 은하 중심 — 최종 규모
- 티어업마다 "이 질량대에선 무엇을 먹는가"가 실제 천문 규모를 가르침.

## 학습 설계 (팝업 퀴즈 금지)
- 새 천체를 처음 먹을 때 **짧고 정확한 한 줄**("중성자별 — 각설탕 한 스푼이 10억 톤"). 게임을 막지 않음.
- **코덱스**: 먹어본 천체 수집 → 실제 사실 열람(리텐션 + 학습).
- **데일리**: 매일 실제 천체 하나(예: 오늘 = 궁수자리 A*) 테마 + 글로벌 랭킹(우리 Supabase 재활용).

## 세션 · 스코어
- 2~4분 런. 점수 = 최고 질량 + 도달 티어 + 생존. 리더보드.
- 짧고 반복 = 서바이버 포화와 정반대의 "한 판 더" 훅.

## 3D 비주얼 (우리 기술 우위)
중력 렌징 포스트프로세스(배경 스타필드 왜곡) + 강착원반(도플러 밝기 비대칭 — 실제!) + 광자 고리. **Three.js r128, nova-surge slice 파이프라인 재활용**.

## 프로토 스코프 (재미부터 검증 — 1일)
메뉴·콘텐츠·티어 없이 **코어 루프 손맛만**:
- 3D 블랙홀 조종(마우스/드래그, 관성 활공)
- 질량값 가진 천체 필드 · 작은 것 먹기(성장) · 큰 것에 먹히기(게임오버)
- **호킹 축소 타이머**(상시 축소, 작을수록 빠름)
- 성장 시 카메라 줌아웃
- **중력 렌징 셰이더 1샷**(배경별 휘어짐 — 시그니처)
- 초록/빨강 후광 가독성
- **검증 질문**: "활공+먹기+축소압력+큰것회피+렌징"이 2분간 재밌나? 렌징이 멋진가? (오너 손맛 판정)

## 리스크 · 열린 질문
- "그래도 hole 게임 아닌가?" — 차별화는 스펙트럼. 축소타이머+렌징+과학이 방어선이나 CG 큐레이터는 패턴매칭할 수도. **de-risk = 프로토 + Poki/교육/itch 타깃 병행 검토.**
- 축소 타이머 밸런스(과하면 스트레스).
- 교육 톤 vs 재미 — 사실은 항상 짧게, 플레이 절대 안 막음.

## 타깃 (열어둠)
웹 포털 지향으로 만들되, 교육 색이 강하니 **Poki·교육 채널·itch가 1차**, CG는 차별화가 먹히면 스트레치. 프로토 반응 보고 확정.
