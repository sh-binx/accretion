# ACCRETION

교육형 3D 블랙홀 아케이드 (코드명 · 변경 가능).

**당신은 블랙홀이다.** 우주를 미끄러지며 먹어치워 커지되, 끊임없이 증발한다 — 멈추면 사라진다. Holey.io식 손맛 + **실제 천체물리를 게임 규칙으로**(호킹 복사 축소 타이머·질량 위계·조석 파괴·중력 렌징) + 3D 렌징 비주얼(2D 클론이 못 하는 것).
