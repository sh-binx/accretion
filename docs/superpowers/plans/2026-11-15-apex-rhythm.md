# 추격전 리듬 개선

## 판단
기존 진화·이벤트가 이미 있으므로 새 콘텐츠 목록을 늘리는 대신 기존 충격파와 포식자를 연결한다. 장르·플랫폼은 유지한다. 실제 천체물리의 정밀 시뮬레이션이 아니라 게임 규칙이며, 충격파가 블랙홀 자체를 약화시킨다고 설명하지 않는다. 가스 공급 중단으로 질량 추종을 잠시 멈춘다는 연출이다.

## 구현 계약
- 충격파는 고정된 위치와 범위를 2초 예고한 뒤 한 번 터진다. 예고 중에는 밀침·보상·잔해 생성 없음.
- 범위에 들어온 네메시스는 8초 동안 플레이어 질량 추종을 멈춘다. 질량을 강제로 낮추거나 자동 처치하지 않는다. 기존 제트 효과는 그대로.
- HUD에 성장 기회의 남은 시간을 표시한다. KO/EN 모두 지원한다.
- 처치 후 다음 네메시스는 12초 뒤 등장한다. 일반 라이벌은 남으므로 무적 시간으로 표현하지 않는다.
- 재시작은 예고와 추격 상태를 초기화한다. 예고 중 중복 이벤트는 무시한다.

## 순서
실패 시험 → 구현 → 새 시험/기존 lategame/nemesis/jet/번역/레이아웃 회귀 → 시각 검수 → 독립 검토 → 스코프 커밋.

## 현재 결과
- 예고 전 폭발 없음 RED 확인 → 예고/적중/빗나감/회복/12초 재등장/재시작/종료 GREEN.
- 독립 검토 P2: 취약 상태에서 공격 창 타이머가 가려짐. 실패 시험 후 두 문구 동시 표시로 수정, KO/EN 검사 추가.
- 실제 브라우저에서 한국어 예고 HUD와 표시 링 확인. 표시가 화면 밖으로 나가던 최초 크기를 현재 카메라 거리 기준으로 줄였다. 1280×800, 844×390 KO/EN HUD 범위 검사 통과. 실제 휴대폰 조작 검증은 남았다.
- 기존 nemesis 13/13, lategame 25/25 통과 회차가 있으나 lategame 재실행은 무작위 위협 표본 70/140 때문에 24/25로 실패했다. 충격파/지형/종착점 항목은 통과. 이를 숨기거나 전체 회귀 통과로 보고하지 않는다. 게임플레이 RNG와 시각효과 RNG 분리 및 표본 검사 재설계가 남았다.
- jets/i18n/overlap 검사는 종료 코드 0. 공개 배포·유료 구매 없음.
