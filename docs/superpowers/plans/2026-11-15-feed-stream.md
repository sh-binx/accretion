# Accretion 흡수 흐름 자원 재사용 구현 계획

> 실행: executing-plans에 따라 직접 구현하고 독립 검토한다.

**Goal:** 흡수 중 프레임별 메시 재생성을 없애면서 흐름의 연속성을 보존한다.
**Architecture:** 슬롯별 BufferGeometry·곡선·샘플 벡터를 한 번 만들고 정점/색상 버퍼만 갱신한다. 기존 게임 규칙은 유지한다.
**Tech Stack:** Three.js r128, 단일 HTML, Playwright 검증.
**Spec:** docs/superpowers/specs/2026-11-15-commercial-polish-design.md

## 제약
외부 에셋·비용 0. main 직접 푸시 금지. 기존 흡수 속도·질량 보상·조작 유지.

## 검토 초점
- 흡수 시작의 짧은 곡선에서 NaN이 생기지 않는가.
- 움직이는 블랙홀과 다중 흐름의 좌표가 유지되는가.
- 프러스텀 경계에서 오래된 경계구로 흐름이 사라지지 않는가.
- 재시작·흡수 종료 후 시각 자원이 남지 않는가.
- 저사양 모드 입자 수 제한이 유지되는가.

## 작업 1: 기준 측정과 자원 재사용
- [x] scripts/verify-stream-resources.mjs: 동일 흡수 중 geometry UUID·생성 수·유한 좌표·끝난 뒤 가시성을 확인하는 실패 시험.
- [x] index.html mkFeedVis: 슬롯별 31×9 정점·색상·삼각형 인덱스, 23개 곡선점과 재사용 곡선/샘플 벡터 준비.
- [x] stepFeed: 재사용 곡선 샘플과 접선으로 튜브 정점을 갱신. 기존 색상 감쇠 유지, 경계구 갱신.
- [x] 신규 시험과 tidal/eat/depth 회귀, 전후 실제 화면 비교.
- [x] 독립 코드 검토 후 스코프 커밋·작업 브랜치 푸시.

## 진행
구현과 독립 코드 검토 완료. 실제 흡수 25프레임에서 TubeGeometry 생성 25→0, geometry 폐기/attribute 교체 0, 프레임별 동일 UUID와 유한 좌표, 흡수 진행 중 재시작 정리를 확인했다. 기존 TubeGeometry와 같은 호 길이 샘플링을 유지한다.

전체 자동 검사 35개 중 34개 통과. verify-ecology는 무작위 후반 먹이 비율 항목에서 21/22로 실패했다. 같은 난수 시드 42·수동 프레임 조건으로 변경 전/후를 대조하면 둘 다 22/22 통과했다. 이 한 번의 대조로 무작위 밸런스 검사가 해결됐다고 보지는 않는다. 기존 회귀 tidal/eat/depth는 46/46 통과. 기하 변경 이후 신규 자원 검사 재통과.

같은 시드·동일 질량·동일 25 흡수 프레임 화면을 전후 확인했다. 흐름/행성 위치와 질량 보상이 동일하며 본체에서 원반으로 휘어지는 흐름을 보존한다. 기존 원반 과노출과 행성 재질은 별도 시각 개선 대상이다. 이는 성능 비용의 첫 개선이며 실기기 FPS나 상용화 완료를 뜻하지 않는다.

공개 배포는 하지 않았다. 에셋 구매·새 지출 없음.
