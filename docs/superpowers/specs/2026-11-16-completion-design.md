# Accretion 클라이맥스 완결 설계
오너 11-16 세 게임 구성·재미·전개 객관적 개선과 확실한 마무리 위임. 기존 성장/흡수 장르·무료 수익모델·플랫폼 유지. 신규 지출 없음.
## 문제와 접근
핵 흡수는 현재 질량/배너만 남겨 종착점이 플레이어에게 완료로 느껴지지 않는다. 새 콘텐츠 대량 추가보다 기존 목표에 성공 결과와 계속 도전하는 선택을 잇는다. 강제 종료는 기존 무한 성장 플레이를 제거하므로 채택하지 않는다.
## 요구
핵 흡수 연출 뒤 성공 패널을 한 번만 연다. 실제 런 시간·최고 질량·점수·선택한 진화들을 보여준다. 계속하기는 상태 보존, 새 판은 기존 begin 경로, 실패화면 재활용으로 승리를 사망처럼 표현하지 않는다. 열린 동안 물리/위협/입력은 정지. 탭이탈 정지는 독립 유지. KO/EN, 키보드 포커스·터치46px, 667x375와960x600에서 스크롤/버튼 접근. 재시작/재입장/핵 재호출 중복보상 금지. 외부 공개/배포는 검증 후 root가 결정.
## 평가
성공→계속→실패→재시작, 성공→새판 흐름을 실제 UI로 검증. 개발 상태 준비 시험과 정상 입력 완주를 별도 기록. 재미 개선은 명확한 보상과 선택이라는 설계가설이며 사람 유지율 실측으로 주장하지 않는다.

## 실물 Safari 후속 11-16
오너가 실물 아이폰 가로 시작·이동·일시정지 정상 동작을 확인했으나 하단이 살짝 가려져 스크롤해야 보인다고 보고했다. 현재 전체화면 버튼은 없다. Safari 툴바가 열린 가시 영역에 렌더러·HUD·조작 버튼·시작 화면을 맞추며, 툴바 변화/회전 때 좌표 계산도 같은 기준을 사용한다. 원인부터 재현하고 수정한다. 정상 모달 자체 스크롤은 보존하지만 플레이 조작부를 찾기 위해 문서를 스크롤하게 하지 않는다. 터치 목표 46px 유지. API 지원 환경만 전체화면 진입/해제 버튼을 표시하고 사용자 클릭에서 호출하며 실패를 무시하지 않는다. iPhone처럼 지원되지 않는 경우 가짜 전체화면 버튼을 만들지 않으며 홈 화면 웹앱 대안을 문서로 안내 가능. 실제 기능 감지로 판단하고 UA만으로 지원을 단정하지 않는다. 미지원 inert 초기값 호환성도 검토하되 범위 혼합하지 않는다.
