# 게임 고도화 설계

## 승인된 방향
2026-11-15 오너: 「권장안대로 하시죠.」 기존 웹·모바일 기반을 우선하며 Accretion → STONE STILL → Skyward 순으로 개선한다. 유료 구매와 게임명 확정은 별도 결정이다. 세 게임 전체의 상용화 완료를 부분 검증으로 선언하지 않는다.

## 접근 비교
- 그래픽만 교체: 빠르지만 후반 반복과 첫 판 이탈은 남는다.
- 전면 PC 게임 재제작: 분량과 플랫폼 변경이 커서 현재 목표보다 과하다.
- 선택한 방향: 기존 규칙을 유지하며 실제 플레이의 목표·피드백·성능을 함께 개선한다.

## Accretion 첫 구현 단위
흡수 흐름은 현재 매 프레임 TubeGeometry를 폐기·재생성한다. 자원 재사용으로 이 비용을 없애고, 원래의 조석 흐름 형태와 잔해 입자·진행 속도는 보존한다. 프레임별 생성 비용 실측과 시각 비교 후 다음 연출 수정을 정한다. 큰 목표를 한 번에 갈아엎지 않는다.

## 다음 구현 단위
후반 목표를 티어별로 다르게 구성하되 기존 진화 선택·네메시스와 중복하지 않는다. 목표 달성·보상·재시작·모바일 HUD를 함께 검증한다. STONE STILL은 첫 판 진입·탐색 단서·위협 전달을, Skyward는 기존 Unity 구현·조작·전투 완주 가능성을 먼저 실측한다.

## 상용화 관문
기존 회귀, 브라우저 실제 플레이, 해상도별 가독성, 프레임/메모리, 저장·재시작, 에셋 라이선스를 확인한다. 실기기 미검증은 분리 보고. 현행 공개판은 검증 전 교체하지 않는다.
